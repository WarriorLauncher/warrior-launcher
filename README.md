# warrior-launcher

An open-source custom launcher and authentication handler for Minecraft: Java Edition.

## Features
- **Secure Microsoft Authentication:** Implements OAuth 2.0, Xbox Live, and XSTS authorization flows.
- **Ownership Verification:** Verifies official game entitlements via Minecraft Services API (`/entitlements/mcstore`).
- **Educational Codebase:** Built with [Forge Deno](https://forge-deno.com) to demonstrate clean authentication and launcher architecture.

## Requirements
- An active Microsoft Account with an owned copy of **Minecraft: Java Edition**.
